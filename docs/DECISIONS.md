# Журнал архитектурных решений

Новые записи добавляются сверху. Номер растёт: D-001, D-002, ...

## Шаблон записи

```markdown
## D-NNN. Короткое название

- Дата: YYYY-MM-DD
- Статус: предложено | принято | заменено D-MMM
- Задача: T-xxx

**Контекст.** Какая проблема, какие ограничения.

**Варианты.** Что рассматривали, плюсы и минусы.

**Решение.** Что выбрано.

**Причины.** Почему именно так.

**Последствия.** Что это меняет, что придётся проверять.
```
