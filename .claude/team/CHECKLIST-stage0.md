# Чек-лист ручной проверки этапа 0 (T-001…T-006)

Запуск: `godot --path .` (fish). Отметь каждый пункт. Всё ниже НЕ проверено автоматически.
Пункты про Dock/Spaces/полноэкранные приложения добавит lead после решения пользователя.

## Квадрат
- [ ] Красный квадрат ~96 px появился по центру рабочей области; фон окна прозрачный, видны рабочий стол и окна.
- [ ] Левая кнопка: квадрат таскается, цвет меняется на оранжевый, при отпускании возвращается.
- [ ] Квадрат не выходит за края рабочей области (меню-бар и Dock не перекрыты).
- [ ] Окно оверлея лежит поверх других окон и не имеет рамки/заголовка.

## Клики сквозь
- [ ] Клик мимо квадрата попадает в приложение/рабочий стол под ним (фокус, выделение, Finder).
- [ ] Клик по меню-бару и по Dock работает как обычно.
- [ ] Прокрутка колёсиком над другим окном работает (вне квадрата).

## Быстрый рывок
- [ ] Схватить квадрат и очень быстро дёрнуть курсор через весь экран: квадрат не теряется, курсор держит ту же точку квадрата.
- [ ] Рывок с отпусканием кнопки за пределами экрана/на другом мониторе: drag завершается, квадрат не «залипает» к курсору.
- [ ] После рывка клики мимо квадрата снова проходят сквозь.

## Retina
- [ ] Курсор при перетаскивании держит ровно ту же точку квадрата (нет смещения в 2 раза).
- [ ] Клик у самого края квадрата ловится, клик в 5 px снаружи уходит сквозь (граница полигона совпадает с видимым квадратом).
- [ ] При смене разрешения/подключении монитора окно подгоняется под рабочую область, квадрат остаётся внутри.

## Выход
- [ ] Правый клик по квадрату закрывает приложение.
- [ ] Правый клик мимо квадрата приложение не закрывает.

## Как закрыть приложение, если квадрат недоступен
Правый клик по квадрату. Иначе из терминала: `pkill -x godot` (fish). Cmd+Q работает, только если у приложения есть меню/фокус, на оверлее это не гарантировано.

## Замер CPU
Покой (fish; запускай приложение в одном окне терминала, замер в другом):
```fish
set pid (pgrep -n -x godot)
top -l 62 -s 1 -pid $pid -stats pid,cpu,mem | grep "^$pid"
```
Игнорируй первые ~10 строк. Не используй `ps %cpu`: на macOS это усреднённое за жизнь процесса значение, оно занижает пики.

CPU при drag:
- [ ] Запусти ту же команду top, во время неё 20 с водить квадрат круговыми движениями.
- [ ] Запиши среднее и максимум. Цель: <= ~30 FPS-режим, разумно < 10% на M1; в покое < 1–2%.
- [ ] Через 0.5 с после отпускания CPU возвращается к уровню покоя.
- Можно через Activity Monitor (вкладка CPU, процесс godot), интервал обновления 1 с.

## Отставание полигона при 5–10 FPS (открытый вопрос 3)
- [ ] Подождать 2+ с без движения мыши (режим покоя 8 FPS), затем сразу схватить квадрат и быстро потащить: захват срабатывает с первого раза, без пропуска нажатия.
- [ ] Нажать на квадрат сразу после того, как курсор вошёл в окно извне: нет «мёртвой зоны» в первые 100–200 мс.
- [ ] Быстро кликнуть по краю квадрата в покое: клик попадает в квадрат, а не в окно под ним.
