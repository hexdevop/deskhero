# Протокол сообщений

Агенты передают друг другу работу файлами в этой папке.

## Имя файла

`YYYYMMDD-HHMMSS_<from>_to_<to>_<T-xxx>.md`. Время брать через `date +%Y%m%d-%H%M%S`.

## Содержимое

```markdown
---
from: godot-dev
to: qa-tester            # имя агента, lead (главная сессия) или all
type: handoff            # handoff | question | answer | bug | report | review
task: T-003
status: open             # open | done
reply_to: <имя файла, если это ответ>
---
## Кратко
## Детали (файлы, функции, решения)
## Что нужно от адресата
```

## Правила

- Адресат после обработки ставит `status: done`.
- Главная сессия периодически переносит `done` в `archive/`.
- Сообщения не дублируют код — только ссылки на файлы и строки.
